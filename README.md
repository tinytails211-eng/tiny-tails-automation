
# Tiny Tails Automation

Automated AI video production system for Tiny Tails TV.

## Workflow

1. Generate story ideas
2. Create scene prompts
3. Generate AI video clips
4. Combine clips into a final video
5. Upload automatically to YouTube
6. Send email notification

## Project Structure

- app/main.py - main controller
- app/story_generator.py - story creation
- app/ai_writer.py - script generation
- app/video_generator.py - AI video connection
- app/video_editor.py - video assembly
- app/youtube_uploader.py - YouTube uploads
- app/email_notify.py - email alerts

## Deployment

The system will run on a cloud VPS and execute automatically.
